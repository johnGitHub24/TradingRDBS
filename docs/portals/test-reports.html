產生報表

先跑驗證，再同步靜態頁，最後從本頁點進 Gradle HTML（bootRun :8095）。

.\scripts\check.ps1
# 內含 gradlew check + aggregateJavadoc + sync-demo-static-artifacts

同埠路徑：/docs/reports/unit/index.html、/docs/reports/integration/index.html。若 404，代表尚未 check／同步。

單元測試報告

偏純邏輯／Mock：Service、Security、Provider 等（類名多為 *Test，不含 Integration）。點模組開 Gradle HTML，再於報表內點對應 class。

Gradle 來源：build/reports/tests/test/index.html

整合測試報告

偏 Spring Boot／API／DB：類名含 Integration 或整合測試套件。點模組開 Gradle HTML 看綠燈／失敗細節。

Gradle 來源：build/reports/tests/integrationTest/index.html

Demo 快捷面板 → 測試報告 →「單元測試／整合測試」連到本頁錨點。Javadoc 另見 /docs/javadoc/（.\gradlew.bat aggregateJavadoc）。
