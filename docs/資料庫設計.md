# 資料庫設計 — TradingRDBS

## 存取鏈

```
Controller → Service (@Transactional) → Repository → H2 / PostgreSQL
```

## ER 圖（3NF）

```mermaid
erDiagram
    ACCOUNTS ||--o{ ORDERS : "1:N"
    SYMBOLS  ||--o{ ORDERS : "1:N"

    ACCOUNTS {
        bigint id PK
        varchar account_no UK
        varchar owner_name
        timestamp created_at
    }

    SYMBOLS {
        bigint id PK
        varchar ticker UK
        varchar company_name
        varchar exchange_code
        timestamp created_at
    }

    ORDERS {
        bigint id PK
        bigint account_id FK
        bigint symbol_id FK
        varchar side
        int quantity
        decimal unit_price
        timestamp created_at
    }
```

## 表清單

| 表 | UK | 索引 |
|----|-----|------|
| accounts | account_no | PK id |
| symbols | ticker | PK id |
| orders | — | account_id, symbol_id |

## Entity 對照

| Java | 表 |
|------|-----|
| `Account` | accounts |
| `Symbol` | symbols |
| `Order` | orders |

## 3NF 檢核

| 檢查 | 結果 |
|------|------|
| orders 無 owner_name | ✓ |
| orders 無 ticker / company_name | ✓ |
| 帳戶更新 owner_name 不需改 orders | ✓ |
| 標的更新 company_name 不需改 orders | ✓ |
