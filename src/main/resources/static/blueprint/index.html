Runtime 總覽

Browser loads same-port Vue static; API calls go through JWT-secured REST.

flowchart LR Browser["Browser / Vue static"] --> API["Spring Boot :8095"] API --> Sec["JWT Filter"] Sec --> Ctrl["REST Controllers"] Ctrl --> Svc["Services"] Svc --> Repo["JPA Repositories"] Repo --> DB[("H2 / PostgreSQL")]

領域／資料流（3NF）

Account(1) → Order(N) → Symbol(1)；OAuth 使用者（app_users）與交易帳戶（accounts）分離。

flowchart TB subgraph auth [OAuth JWT] U[app_users] --> JWT[JwtTokenProvider] end subgraph domain [3NF] A[accounts] --> O[orders] S[symbols] --> O end Browser --> JWT JWT --> API["/api/v1/*"] API --> domain
